# What you can type

LoreStudio has short ways to do things as you write: a character or two that open a picker, a key that turns a line into something else. None of them is needed. Each one saves you a trip to a menu or a panel, and most work the same in prose and in a script.

Type `/` anywhere in the text for the list of commands; each says the quicker way, if it has one. **?** shows the keys too. A tick below marks each one you have used.
