# What you can type

LoreStudio has short ways to do things as you write: a character or two that open a picker, a key that turns a line into something else. None of them is needed. Each one saves you a trip to a menu or a panel, and most work the same in prose and in a script.

Type `/` anywhere in the text for the list of commands; each says the quicker way, if it has one. **?** shows the keys too. A tick below marks each one you have used. To try the main ones in a scrap of prose, see [Try them out](/guides/practice).

## Tips while you write

When you do something the long way, such as Insert image from the ⋯ menu or a speaker written out after a quote, a tip above the word count names the quicker way. It waits for a pause in your typing and goes after a few seconds. You get two a session at most, and never one for something you already use. An empty scene names one too. Turn them off in **Settings › Writing**.
